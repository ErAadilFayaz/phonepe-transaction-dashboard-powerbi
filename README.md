# PhonePe Transaction Dashboard | Power BI

## Overview
This project is an interactive Power BI dashboard built to analyze PhonePe transaction data. It provides insights into transactions, users, transaction value, and success rate through interactive visualizations.

## Features
- Total Transactions
- Total Transaction Value
- Unique Users
- Success Rate
- Monthly Transaction Trend
- Payment Status Analysis
- Age Group Analysis
- Interactive Slicers

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key DAX Measures
- Total Transactions
- Total Transaction Value
- Total Users
- Successful Transactions
- Success Rate
